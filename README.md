# Desafio DIO - Gemini Notebook

## Visão Geral do Trabalho

Neste projeto foi utilizado o **Gemini Notebook** com o objetivo de auxiliar nos estudos para concursos públicos. A ferramenta permite trazer informações de diversas fontes de forma ágil. O Gemini Notebook pode ser utilizado por estudantes de diversos níveis, pois a ferramenta pode apresentar conteúdos completos, tirar dúvidas e auxiliar nas revisões.
  
## Etapas do Projeto

### 1. Carregamento das Fontes

Foram inseridos documentos em formato PDF contendo os resumos e materiais necessários para a consulta.

### 2. Prompts

* Prompts podem ser formulados de forma simples, com perguntas diretas ou direcionamentos, como a busca por um tópico específico: "Faça tópicos explicando quais são os tipos de improbidade administrativa"
* Podem ser utilizados para responder questões e revisar matérias.
* Para um estudo inicial através de diversas fontes é possível criar um material completo focado no edital do concurso ou até mesmo um resumo com os pontos mais importantes de uma matéria.

## Conclusões

***Eficiência no Consumo de Informações:** O Gemini Notebook pode acelerar os estudos, disponibilizando uma grande quantidade de material em pouco tempo. Aos que não são adeptos às videoaulas é um bom recurso para criar material escrito.

***Confiabilidade das Fontes:** As fontes são selecionadas pelo usuário, isso traz uma maior confiabilidade nos recursos, podendo evitar a utilização de informações equivocadas.

***Facilidade de Uso:** É uma ferramenta simples de usar e oferece diversos recursos valiosos para otimizar a rotina de estudos.
